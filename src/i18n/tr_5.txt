The concept of an {{Event}}
@@855
An event is something that happens to an object, such as clicking it, double-clicking it, or passing the mouse over it.
@@856
Every object has its own events.
@@857
And all code linked to an object must be run by an event.
@@858
This gives the language its power: you can program one object for each of its events.
