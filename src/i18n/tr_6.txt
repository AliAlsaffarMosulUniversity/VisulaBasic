1) Local variables {{Local}}
@@1036
Declared inside an object's procedure. Nothing outside it can use them.
@@1037
Each procedure has its own variable even if the names are the same. Each one is in a different memory location.
@@1038
If you declare a variable inside one procedure and then use it in another, it will not be recognised. It is better not to vary the names of local variables, so as not to confuse yourself.
